developer tools
===============

the tools for working on the kernel, rather than the kernel itself.

- `kernel selftests <kselftest.rst>`_: programs that check, from ring 3,
  what the kernel promises ring 3. running them, writing one, and what a
  failing one means.

the rest of the checks, the host suites, the boot test and the static
ones, are in `testing <../testing.rst>`_.
